# NEXA Platform - Beta Release (1.0.0-beta.1)

Welcome to the first official beta release of the NEXA Platform!

## What's New
- **Full-Stack Architecture**: A stable Express backend proxying advanced ML pipelines in Python, interfaced by a lightning-fast React frontend.
- **NEXA Mobile**: A Flutter-based companion application allowing seamless Chat, Voice, and Vision integration on the go.
- **Voice Engine**: Real-time STT and TTS utilizing local and remote provider configurations.
- **Vision Integration**: Extract text and context from images and PDF documents instantly.
- **NEXA Studio**: Administer the platform, monitor performance, and configure RAG/Agent pipelines in real-time.
- **Multi-Agent RAG**: Autonomous agent orchestration with memory persistence and retrieval.
