# NEXA Quick Start Guide

Welcome to NEXA! Follow these steps to get started immediately after installation.

## 1. Accessing the Web Interface
- Navigate to `http://localhost`.
- You will see the main Chat interface. Try sending a basic prompt to test the LLM integration.

## 2. Testing Voice & Vision
- **Voice**: Click the microphone icon in the input bar to begin streaming voice dictation. Ensure browser microphone permissions are allowed.
- **Vision**: Click the camera icon or upload an image file. The backend will parse the image context and inject it into your prompt.

## 3. Using NEXA Studio (Admin)
- Access the Studio by clicking the **Studio** button in the sidebar or navigating to `/studio`.
- View memory logs, agent routing activity, and system health status in real time.

## 4. Setting Up the Mobile Companion App
- Install the APK or run via Xcode.
- Log in with any username (beta authentication simulates backend connection).
- The mobile app synchronizes perfectly with your local NEXA instance.
