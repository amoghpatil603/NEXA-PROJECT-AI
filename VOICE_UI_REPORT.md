# Voice UI Report

## Interfaces
- **VoiceRecorder**: Features an animated pulse indicator, recording state toggles, and live interim transcript previews.
- **VoicePlayer**: Embedded into chat cards alongside copy buttons, equipped with dynamic play/stop toggling.
- **NEXA Studio Voice Manager**: A dedicated administration dashboard offering real-time stream status, provider selections, and slider-based playback speed control.

All components adhere to the existing Slate/Indigo Tailwind design language and utilize standard Lucide icons for consistency.
